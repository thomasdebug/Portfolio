PORTFOLIO TEMPLATE — START HIER

1. Open index.html in your browser.
2. Vervang overal "JOUW NAAM" door je naam en pas de profieltekst aan.
3. Zet je profielfoto in assets/me.jpg.
4. Vervang assets/preview-placeholder.svg bij elk project door je eigen screenshot of GIF.
   Voorbeeld: <img src="assets/card-combat.png" alt="Gameplay van mijn card combat prototype">
5. Pas per project de titel, uitleg, tags, GitHub-link en projectpagina-link aan.
6. Kopieer project-template.html voor afzonderlijke projectpagina's, of gebruik het als startpunt.
7. Vervang de contactgegevens in index.html en het e-mailadres in script.js.
8. Zet je CV als assets/cv.pdf.
9. Vul per project echte screenshots, GIF/video, code snippets, README en speelbare build-links in.
10. Publiceer bijvoorbeeld via GitHub Pages. Voor Unity WebGL builds moet je build-map online hosten.

RUBRIC-CHECK
- Persoonlijkheid: About Me, stagewens, professioneel profiel, contactlinks en devlog.
- Projecten: 6 voorbeeldkaarten; vul minimaal 5 echte relevante projecten in. Elke case study moet tekst, beeld/GIF/video, jouw aandeel, code en links bevatten.
- Vormgeving: consistente kleuren, duidelijke naam/rol, leesbare typografie, responsieve layout.
- Praktisch: sticky navigatie die niet verdwijnt, mobiele menu, filters, CV-link, contactformulier dat mailto opent.
- Professioneel profiel: pas titel en projecten aan op gameplay programming / jouw gewenste richting.
- Code: echte GitHub repositories, leesbare snippets, README, beschrijvende commits en waar nuttig class diagrams.
- Expert-level onderdelen zoals online speelbare builds, actieve blog en volledige projectinformatie moet je zelf invullen; dit template maakt daarvoor ruimte maar kan geen echte projectinhoud verzinnen.

LET OP
Het contactformulier gebruikt mailto en verzendt niet rechtstreeks via de website. Voor echt verzenden zonder e-mailprogramma heb je een backend of formulierdienst nodig.
