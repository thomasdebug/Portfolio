Mechanics & features

  • Enemy Attack: the enemy attacks when in a certain radius of the player.
  • Enemy Death: Enemy dies at 0 hp

    • Code snippet

    // Voorbeeld: vervang dit door eigen code
    private void Attack()
    {
        float dist = Vector3.Distance(_enemyDetection._player.position, transform.position);
        if (_attackCooldown >= 1f && dist <= _enemyAI._attackRange) 
        {
            Vector3 direction = _enemyDetection._player.position - transform.position;
            Vector3 startPos = transform.position;
            Vector3 targetPos = startPos + direction.normalized * _dashDistance;
            
            Vector3.MoveTowards(transform.position, targetPos, 10f);
            _attackCooldown = 0f;
        }   
    }

    i used an attack cooldown to make it not instantly jump at the player and i made it calculate the position and Distance using the vectors and then i made it dash towards the player while overshooting so that it looked like it was just dashing.
